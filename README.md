# Assigning Roles in Microsoft Azure's Entra ID

## Objective

Assign administrative directory roles to a user account in Microsoft Entra ID.

## Scenario

This lab simulated granting a user the specific administrative permissions needed for their job function by assigning directory roles rather than broad, unnecessary access.

## Tasks Completed

- Opened the Directory roles panel to review available admin roles.
- Assigned the Exchange Administrator, Hybrid Identity Administrator, and Printer Technician roles to Kyle Roberts.
- Confirmed the roles were applied to the account.

*Note: These three roles were selected specifically to practice assigning different types of directory roles in one exercise, not to reflect a realistic real world role combination for a single employee.*

## Skills Demonstrated

- Role-Based Access Control (RBAC)
- Directory Role Assignment
- Identity and Access Management
- Least-Privilege Access Principles

## What I Learned

This lab reinforced why role assignment should be deliberate,each role grants specific administrative power, so assigning only what's needed for someone's job function matters for keeping access secure and auditable.

- Microsoft Azure Entra ID
- Windows 11
